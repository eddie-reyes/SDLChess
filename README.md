# SDLChess (SDL2)

A lightweight 2D chess engine built with **C++**, using **SDL2** for graphics rendering.  
The project compiles using the **MSVC** toolchain in **Visual Studio 2022** 

---

## 🔥 Features

### ♟ Chess Engine
- Full board representation (8×8)
- Legal move validation for all pieces
- Turn management (white/black)

### 🎨 Graphics (SDL2)
- 2D graphics rendering using SDL2
- Chessboard + piece sprites (.bmp)
- Texture loading and cleanup
- Frame-based update loop

### 🛠 Build System
- Fully configured for **Visual Studio 2022**
- Uses **MSVC** compiler and standard C++ toolset
- SDL2 linked via:
  - `SDL2.lib`
  - `SDL2main.lib`
  - `SDL2.dll` (runtime)
